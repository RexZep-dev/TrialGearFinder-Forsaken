# Trial Gear Finder: Forsaken Dungeons+

Модуль аддона [Trial Gear Finder](https://www.curseforge.com/wow/addons/trial-gear-finder):
рейтинг сайта [Forsaken Dungeons+](https://forsaken-dungeons.online) в подсказке
игрока и в списке гильдии — место, рейтинг, рейды, лучшее подземелье и рейтинг
по уровням ключа (+20 … +45). Бывший аддон ForsakenIO.

Аддоны в игре не выходят в интернет, поэтому данные — снимок сайта внутри
модуля. Снимок обновляется каждый день: если рейтинг изменился, выходит новая
версия. Снимку больше трёх дней — подсказка об этом скажет.

Как выпускать новые версии — [RELEASING.md](RELEASING.md).

Команды: `/fdio` — сводка по себе и цели, `/fdio tooltip` — включить или
выключить подсказку.
