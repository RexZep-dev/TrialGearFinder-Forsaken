# Как выпускать модуль

Модуль показывает в игре рейтинг сайта forsaken-dungeons.online. Аддоны в WoW
не ходят в интернет, поэтому рейтинг лежит внутри модуля снимком —
`db/Database.lua` — и уезжает игрокам новой версией на CurseForge
(проект 1723361).

## Рейтинг — само, каждую ночь

В 06:00 по Москве GitHub запускает задание **Daily snapshot**
(`.github/workflows/daily.yml`):

1. `tools/sync.js` берёт данные сайта (только публичные GET):
   `/api/season/current`, `/api/leaderboard-detailed?mode=season`
   и `/api/character/{id}` ради рейдов и лучших прохождений.
2. Рейтинг изменился — коммит снимка, версия по дате (`2026.10.04`,
   второй выпуск за день — `2026.10.04.2`), архив на CurseForge.
3. Не изменился — ничего не выпускается.

Руками здесь ничего делать не нужно.

## Правка кода — залить и нажать кнопку

1. Поменяй файлы в ветке `master` — прямо в браузере на GitHub
   (карандаш «Edit») или у себя и `git push`.
2. **Actions** → **Daily snapshot** → **Run workflow** → поставь галочку
   **«Выпустить сейчас»** → **Run workflow**.
3. Через минуту-две новая версия на CurseForge.

Без кнопки правка уедет с ближайшим ночным выпуском, но только в день,
когда изменится рейтинг.

> **Всё, что лежит в `master`, уходит игрокам при следующем выпуске.**
> Проверь правку в игре до того, как залить.

### Проверить в игре до выпуска

Скопируй папку репозитория в `World of Warcraft\_retail_\Interface\AddOns\`
под именем `TrialGearFinder_Forsaken` (нужен и сам аддон Trial Gear Finder),
перезапусти игру, наведи мышь на игрока из таблицы рейтинга. `/fdio` — сводка
по себе и цели. Новые файлы в папке игра видит только после полного
перезапуска, `/reload` хватает для правок в уже существующих.

## Что в архиве у игрока

`TrialGearFinder_Forsaken.toc`, `Locales.lua`, `Forsaken.lua`,
`db/Database.lua`. Остальное (`tools`, `.github`, эти записки) — только
для сборки, список исключений — `.pkgmeta`. Новый файл для игры — допиши
его в `.toc`.

## Если что-то поменялось на сайте

- **Поменялся ответ API** — правится `tools/sync.js`. Проверить у себя:
  `node tools/sync.js` в папке репозитория, он перепишет `db/Database.lua`.
- **Новое подземелье в сезоне** — в журнале задания будет строка
  «подземелье без перевода: …». Допиши его в `tools/names.json`:
  `{ "ru": …, "en": …, "zh": … }` (названия — с Wowhead, подсказка
  зоны на русском, английском и китайском). Пока не дописано,
  в подсказке будет английское название.
- **Поменялись цвета или формула места на сайте** — `rankColor` в
  `tools/sync.js`, она повторяет `leaderboardRankColor` сайта.

## Где смотреть, прошёл ли выпуск

- **Actions** — каждый запуск; в шаге «Собрать и выложить» строка
  `Uploading … to https://wow.curseforge.com/projects/1723361` и `Success!`.
- **Releases** на GitHub — архив каждой версии.
- CurseForge — вкладка Files проекта.

## Не трогать

- Секрет `CF_API_KEY` (Settings → Secrets) — ключ загрузки на CurseForge.
- `## X-Curse-Project-ID: 1723361` в `.toc` — куда загружать.
- `## Version:` в `.toc` ставит задание само, по дате.
